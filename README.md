Разработчик: Файзуллин Радмир, группа 4ИС-1  
Среда эксплуатации:ПК под управлением ОС Windows  
  1. Описание и архитектура системы
Информационная система предназначена для автоматизированного сбора структурированной информации с веб-ресурсов, сохранения записей в базу данных SQLite с защитой от дублирования и быстрого поиска/выгрузки данных через десктопный интерфейс или локальный API.

Структура проекта (`faizullin_db_system`)
* `desktop_app.py` — графический интерфейс пользователя (Модуль 2: управление парсером, Модуль 6: поиск, фильтрация и экспорт).
* `parser_module.py` — модуль сбора, очистки и нормализации веб-данных (Модуль 1).
* `query_service.py` — скрипт параметризованной выборки, сортировки и пагинации из БД (Модуль 4).
* `api_layer.py` — локальный REST API (`/api/items`) для интеграции и программного доступа (Модуль 5).
* `database.py` — слой доступа к БД SQLite и инициализация таблиц `items` и `parse_logs` (Модуль 3).
* `database.db` — файл локальной базы данных SQLite.
* `config.py` — модуль загрузки настроек из файла окружения `.env`.
* `.env` / `.env.example` — конфигурация параметров среды и её шаблон.
* `requirements.txt` — список зависимостей Python.
* `system.log` — файл журнала работы и ошибок системы.
* `Инструкция.txt` / `README.md` — документация по развёртыванию и эксплуатации ИС.

2. Инструкция по установке и запуску на ПК (Windows):

  Шаг 1. Подготовка окружения
1. Убедитесь, что на ПК установлен **Python 3.10** или выше (`python --version`).
2. Клонируйте репозиторий в рабочую директорию (например, `C:\faizullin_db_system`).
3. Откройте терминал в папке проекта и создайте виртуальное окружение:
   ```powershell
   python -m venv venv
   ```
4. Активируйте виртуальное окружение:
   ```powershell
   .\venv\Scripts\activate
   ```
5. Установите зависимости:
   ```powershell
   pip install -r requirements.txt
   ```

 Шаг 2. Настройка конфигурации
1. Скопируйте шаблон `.env.example` и переименуйте его в `.env`:
   ```powershell
   copy .env.example .env
   ```
2. При необходимости отредактируйте параметры подключения к БД и логирования в `.env`.

 Шаг 3. Запуск системы
1. Запуск десктопного приложения ИС:**
   ```powershell
   python desktop_app.py
   ```
2. Запуск локального API-сервера (для внешней интеграции):**
   ```powershell
   python api_layer.py
   ```
   Проверка API:* `http://127.0.0` (порт согласно `config.py`).

## 3. Краткое руководство пользователя
1. *Сбор данных (Вкладка «Управление парсером»):
   * Укажите шаблон целевого URL (с `{page}`), категорию и глубину страниц.
   * Нажмите «Запустить парсинг». Ход выполнения выводится в окно логов и сохраняется в `parse_logs`.
2. Поиск и экспорт (Вкладка «Поиск и выдача данных»):
   * Задайте ключевое слово, категорию, диапазон цен и сортировку, затем нажмите «Найти».
   * Двойной клик по строке открывает URL источника в браузере.
   * Для выгрузки результатов используйте кнопки «Экспорт в CSV» или **«Экспорт в JSON».
